# 第一期视频：7×24 自动交易

这是 Creator OS V2 唯一保留的旧项目素材身份目录，也是后续 Golden Episode 的固定入口。

## 为什么 GitHub 里没有原始 MP4

历史 `main` 分支从未跟踪 `第一期视频_7x24自动交易` 这批本地二进制素材；它们原先只存在于本机/历史会话产物中。因此，不能通过从 `main` 合并来“恢复”一个从未提交过的文件。

V2 已恢复并锁定原始母带身份，见 `source-manifest.json`。完整本地迁移包会把真实 `原始录屏.mp4` 与新 V2 项目放在一起，用户解压后即可直接替换旧 `video` 文件夹，不需要再运行清理脚本。

## 母带规则

- 只认 `source-manifest.json` 中 SHA-256 对应的原始录屏；
- 旧 `preview-*`、`v4/v5/v6/v7/v8`、`final_final_lock` 等均不是素材母带；
- 旧失败成片只允许作为负样本，不再复制回 V2；
- 成片必须从真实 UI / 真实交易所证据重新构建；
- 模拟盘账户变化不能表述成稳定盈利。

## 本期唯一故事

`5000U → 约7350U` 是钩子；真正要证明的是：一个由 AI Agent 协助实现的自动交易系统，是否从本地判断、风控、Why No Trade 到交易所侧账户/订单核对形成了真实闭环。
