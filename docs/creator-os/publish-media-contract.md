# Publish Media Contract

A release candidate is blocked unless all of these are true:

- One visual evidence plane only; no duplicated top/bottom evidence panels.
- Screen evidence is readable at 1080x1920 and may use semantic pan/zoom, never blind center crop.
- Audio stream exists and is audibly non-silent, not merely decodable.
- Final media is visually inspected from representative timestamps after the last render.
- Technical decode/codec checks are necessary but never sufficient for publish approval.
