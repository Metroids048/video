# EP01 V3 QA notes

Release-blocking visual rules for the regenerated portrait cut:

1. Never show the same source as simultaneous top/bottom evidence panels.
2. Every timestamp has exactly one primary source viewport.
3. Wide desktop recordings are adapted by semantic crop/pan over time, not by shrinking a complete desktop into a tiny landscape card.
4. No crop may expose an obviously incomplete duplicate panel.
5. Audio must be present and audibly non-silent; codec presence alone cannot pass QA.
