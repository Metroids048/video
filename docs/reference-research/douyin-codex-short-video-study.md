# 抖音 / Codex 短视频参考研究（Creator OS V2）

本文件只保留可复用的创作原则，不再附带旧 WorkBuddy 示例仓库或 gitlink。

## 可复用原则

1. 开头 1–3 秒先给真实结果、冲突或证据，不使用品牌片头、项目介绍页或 PPT 式总览。
2. 屏幕纪录片以真实 UI、真实操作和真实结果为主体；生成卡片只用于必要解释。
3. 横屏录屏进入竖屏时，优先“建立场景 + ROI 局部聚焦”，不能把整张横屏缩成手机上看不清的一条。
4. 字幕服务于理解，不重复整段口播，不遮挡余额、订单、仓位、图表或 Why No Trade 等关键证据区。
5. 一条视频只讲一个核心故事：一个问题、一个结果、一个下一步钩子。
6. 参考视频的价值是抽取 hook、节奏、镜头语法和信息密度，不是复制文案或受版权保护画面。
7. Creative Review 必须基于实际 MP4 / 移动端预览观看，而不是根据 timeline、JSON 或技术 QA 猜测质量。

旧 `workbuddy-samples/video-workshop` gitlink 已从 V2 删除；它既不属于 Creator OS V2 能力层，也不应继续制造 checkout/submodule 警告。
