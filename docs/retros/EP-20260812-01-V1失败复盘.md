# EP-20260812-01 V1 失败复盘

## 结论

V1 正式判定失败，Creative Gate 不批准。V1 的 `creative-review.json` 分数为
`null`，Episode 仍停在 `ROUGH_CUT_READY`/`visual-review` 阻塞状态。不能在旧
timeline 上修补；V2 必须从冻结 VCI 包和原始录屏工作副本建立新 timeline。

## 根因

工程 QA 只验证 MP4、分辨率、字幕和 FFmpeg 产物，没有在完整渲染前验证首帧、
手机可读性、真实证据利用率和继续观看意愿。旧链路让脚本完整性、HyperFrames
卡片数量和技术合法性代替了导演判断，导致真实 Binance、K 线、Why No Trade、
订单历史被缩成邮票，而非成为画面主体。

## V2 约束

V2 使用 `production_type=SCREEN_DOCUMENTARY`：真实录屏至少 80%，生成卡最多 2
张且总时长不超过 6 秒，无标题/logo/PPT 片头；先生成 A/B/C 三个 8-10 秒 Pilot，
由两个独立 Reviewer 实际观看后才允许完整渲染。无真实评分时必须 BLOCKED。
